Features

What the plugin does

Real crash physics, a complete on-foot mode and track objects shared between players.

01

Crash & ragdoll

  • Physics ragdoll on every crash; the rider rolls on the real track surface.
  • Helmet, boots, arms and legs don't go through the ground, walls or track objects.
  • Natural get-up: rolls over, gets on all fours, one knee, then stands.
02

On foot

  • Walk, run and jump back to your bike, lift it and get back on.
  • Crouch (Shift or right stick click).
  • Get off the bike when stopped.
  • 1st or 3rd person camera, 4-level zoom and adjustable field of view.
03

Track objects

  • Cones: place, pick up, carry, push, put down or reset them.
  • Hay bales: the round bale is a solid wall; the small one can be pushed and carried.
  • FMX ramps: 8 shapes, 4 colours, rideable at any height, shown in replays.
  • Furniture: a folding table and camping chairs you can sit on.
04

Online

  • Host with the button ON and RAGDOLL is added to your server name.
  • See other players fall, walk and lift their bikes; players collide with each other.
  • Cones, hay bales and ramps are shared between players.
  • Optional: auto-kick players without the plugin (off by default).
05

Automatic updates

  • The plugin checks for new versions at game start and asks you on the track whether to install them.
  • Every update is verified (SHA-256) before it is installed.
  • Can be turned off, or set to install without asking, in menu P.
06

Settings

  • Menu P: keys, language, rider, helmet and boots.
  • Gamepad buttons drawn as Xbox or PlayStation symbols (auto-detected, Steam Input included).
  • Short tutorial on first launch, optional on-screen key hints.

Installation

  1. Download MXRP_Beta_x.x.zip and unzip it.
  2. Run the .exe installer. It finds MX Bikes by itself.
  3. It removes old versions and keeps your settings.
  4. Start the game and press P to open the plugin menu.
  1. Download MXRP_Beta_x.x_manual.zip and unzip it.
  2. Copy the content of its plugins folder into the plugins folder of MX Bikes (next to mxbikes.exe).
  3. Remove any old version of the plugin.
  4. Start the game and press P.

Uninstall: delete MXRP_Ragdoll* from the game's plugins folder, and the Documents\PiBoSo\MX Bikes\MXRP_Ragdoll folder if you don't want to keep your settings.
